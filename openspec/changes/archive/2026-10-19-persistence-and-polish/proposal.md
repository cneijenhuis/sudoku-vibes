# Proposal

## Why

The game works, but it behaves like a web page rather than a phone game: refreshing or closing the tab loses the puzzle, it needs a network on every visit, the Android Back button leaves the app instead of going back, and nothing responds to touch with feedback. This change closes those gaps.

## What Changes

- **Save and resume:** the game in progress is saved automatically in the browser. The start menu offers "Resume" for it; resuming opens the game paused. Quitting to the menu keeps the game; starting a different game asks before replacing it. Finishing a game clears the save.
- **Installable and offline:** a web app manifest and icons make the game installable to the home screen, and a small service worker caches the app so it opens and plays with no connection.
- **Haptics:** short vibrations on a mistake, on entering/leaving number-first mode and on completing a puzzle, with an on/off toggle in the menu (shown only where vibration is supported).
- **Back button:** the browser/Android Back button returns from loading, game and results to the menu instead of leaving the app.

## Capabilities

### New Capabilities
- `game-persistence`: Saving, validating, resuming and clearing the game in progress.
- `offline-pwa`: Installability and offline play via manifest, icons and a service worker.
- `haptic-feedback`: Vibration feedback and its setting.
- `back-navigation`: Mapping the browser Back button onto in-app navigation.

### Modified Capabilities
- `game-timer`: Quit to menu keeps the game instead of discarding it.
- `start-menu`: Shows a Resume entry when a saved game exists, a replace confirmation, and the haptics toggle, while still fitting 375x667.

## Impact

New modules: `src/storage/` (serialise/restore, localStorage access), `src/pwa/` (service worker registration), `public/` (manifest, icons, `sw.js` or generated by a build step), `src/ui/haptics.ts`, history handling in the router. Changes to `vite.config.ts`, `index.html`, `src/ui/{app,menu,game,router}.ts`, `src/game/state.ts` (restore), tests, README. No new npm dependencies.
